Embedded System คือคอมพิวเตอร์ขนาดเล็กที่ฝังอยู่ในอุปกรณ์ อ่านค่าเซนเซอร์ ตัดสินใจตามโปรแกรม แล้วสั่งไฟ มอเตอร์ จอ หรือส่งข้อมูลออนไลน์ ลองเลื่อนอุณหภูมิด้านล่างดูได้เลย

Embedded คืออะไร

ระบบ Embedded ทุกตัวมีวงจร 4 ส่วนเหมือนกัน

Input

เซนเซอร์ เช่น อุณหภูมิ แสง ปุ่มกด กล้อง เสียง

Process

ไมโครคอนโทรลเลอร์ (MCU) ประมวลผลตามโค้ด

Output

LED จอ รีเลย์ มอเตอร์ เสียง

Communication

Wi‑Fi, Bluetooth, MQTT หรืออินเทอร์เน็ต

ทำไมต้องเรียน

สมาร์ตโฮม หุ่นยนต์ รถยนต์ เครื่องวัด โดรน และระบบฟาร์มอัจฉริยะ ล้วนใช้ Embedded System เพื่อให้อุปกรณ์คิดและทำงานเองได้ การเรียนจึงไม่ใช่แค่จำชื่อบอร์ด แต่คือเข้าใจว่าบอร์ดแต่ละแบบถูกสร้างมาแก้ปัญหาอะไร และควรเลือกใช้เมื่อไร

บอร์ดยอดนิยมในการสอน

เลือกสิ่งที่อยากทำ แล้วดูว่าบอร์ดไหนเหมาะ

Arduino Uno

เกิดมาเพื่อให้มือใหม่คุมฮาร์ดแวร์ได้ง่าย ควบคุม LED เซนเซอร์ มอเตอร์ด้วย C/C++

เริ่มต้นวงจรและการควบคุม

micro:bit

สอน Coding/STEM ให้เห็นผลเร็ว เขียนแบบบล็อก JavaScript หรือ Python มี LED และเซนเซอร์ในตัว

นักเรียนมัธยม ผู้เริ่มต้น

ESP32

เกิดมาเพื่อทำ IoT ส่งข้อมูลเซนเซอร์ผ่าน Wi‑Fi/MQTT ควบคุมผ่านเว็บหรือแอป

IoT, Smart Home, Smart Farm

Raspberry Pi Pico

MCU ราคาถูกที่ยืดหยุ่น ใช้ MicroPython หรือ C/C++ ควบคุมฮาร์ดแวร์

เริ่มจาก Python

Raspberry Pi

คอมพิวเตอร์ขนาดเล็ก ไม่ใช่แค่ MCU รัน Linux เว็บ กล้อง AI ฐานข้อมูล

งานประมวลผลหนัก

TESAIoT Dev Kit

รวม Embedded, IoT, ความปลอดภัย และ Edge AI ไว้ในชุดเดียว อ่านเซนเซอร์ แสดงจอ ส่งข้อมูล และรัน AI บนบอร์ด

โครงงาน AIoT และ Edge AI
กฎง่าย ๆ: อยากควบคุมไฟ/มอเตอร์ เริ่มที่ Arduino หรือ Pico · อยากต่ออินเทอร์เน็ต เลือก ESP32 · อยากทำ AI บนอุปกรณ์ เลือก TESAIoT Dev Kit หรือ Raspberry Pi

วิธีใช้บอร์ดจริง

  1. ต่อวงจร เช่น LED กับขา GPIO ผ่านตัวต้านทาน
  2. เขียนโค้ดสั่งให้ขา GPIO เปิด-ปิด LED
  3. อัปโหลดโปรแกรมจากคอมพิวเตอร์เข้าบอร์ด
  4. ทดสอบและแก้ปัญหา ตรวจสาย โค้ด และเซนเซอร์
  5. ต่อยอด เพิ่มจอ Wi‑Fi MQTT กล้อง หรือโมเดล AI

TESAIoT Dev Kit

บอร์ดพัฒนาสำหรับ AIoT และ Edge AI สร้างบนชิป Infineon PSoC Edge E84 รวม MCU หลายคอร์ NPU สำหรับ AI Wi‑Fi 6 เซนเซอร์ในตัว และจอสัมผัสไว้ในบอร์ดเดียว

บอร์ดทั่วไปเหมาะกับการเริ่มต้น แต่เมื่อโครงงานต้องตรวจจับภาพ เสียง หรือการเคลื่อนไหวบนบอร์ดเอง ต้องมี NPU และหน่วยความจำมากขึ้น จึงออกแบบให้เป็น “ห้องแล็บพกพา” สำหรับ Embedded, IoT, ความปลอดภัย และ Edge AI

ส่วนมีอะไรใช้ทำอะไร
ชิปหลักCortex‑M55 400 MHz + Helium DSP + Ethos‑U55 NPUประมวลผลและรัน Edge AI
ความปลอดภัยTrustZone, Secure Boot, OPTIGA Trust Mป้องกันเฟิร์มแวร์และการเชื่อมต่อ
หน่วยความจำQSPI NOR 512 Mb, HYPERRAM 128 Mb, LittleFS 52 MBเก็บโปรแกรมและข้อมูลระบบ
การสื่อสารWi‑Fi 6 dual-band + Bluetooth LEต่ออินเทอร์เน็ตและอุปกรณ์ไร้สาย
เซนเซอร์ในตัวIMU, เข็มทิศ, แรงดัน, อุณหภูมิ/ความชื้น, เรดาร์ 60 GHz, กล้อง, ไมโครโฟนตรวจจับการเคลื่อนไหว สภาพแวดล้อม เสียง และภาพ
จอจอสัมผัส 4.3 นิ้ว MIPI DSIสร้างหน้าจอควบคุมและแสดงผล
การขยายmikroBUS ×3, Arduino shield, CAN, RS‑485ต่อโมดูลภายนอกเพิ่ม

ผู้เรียนทำอะไรกับบอร์ดได้

  • อ่านค่าเซนเซอร์ เช่น อุณหภูมิ ความชื้น แรงดัน ความเร่ง และเรดาร์
  • ควบคุม LED ปุ่ม CapSense GPIO และจอสัมผัส
  • แสดงเมนูหรือแดชบอร์ดบนจอด้วย LVGL
  • ส่งข้อมูลผ่าน Wi‑Fi/MQTT ไปยังระบบ IoT
  • รันโมเดล AI บน NPU ให้อุปกรณ์ตัดสินใจเองโดยไม่ต้องส่งข้อมูลทั้งหมดขึ้นคลาวด์
ตัวอย่างโครงงาน: วัดอุณหภูมิและความชื้น → แสดงค่าบนจอ → เปิดพัดลมเมื่อร้อนเกินกำหนด → ส่งข้อมูลผ่าน MQTT → ใช้เรดาร์ตรวจว่ามีคนอยู่ใกล้หรือไม่

หลักสูตร ม.บูรพา

วิศวกรรมระบบสมองกลฝังตัวและอิเล็กทรอนิกส์สื่อสาร ปริญญาตรี วศ.บ. 4 ปี รวม 136 หน่วยกิต

เรียนอะไร

  • การเขียนโปรแกรมและคอมพิวเตอร์สำหรับวิศวกร
  • วงจรไฟฟ้าและอิเล็กทรอนิกส์
  • ระบบสมองกลฝังตัว: MCU, GPIO, เซนเซอร์, การควบคุมอุปกรณ์
  • การสื่อสาร: Wi‑Fi, Bluetooth, เครือข่าย, IoT, MQTT
  • ระบบควบคุมและหุ่นยนต์
  • AIoT และ Edge AI: ให้อุปกรณ์วิเคราะห์ข้อมูลบนบอร์ดได้
  • โครงงานและการออกแบบระบบจริง

ทำไมผสม 3 ส่วนนี้

Embedded

ทำให้อุปกรณ์ “คิดและควบคุม” ได้

Electronics

ทำให้อุปกรณ์ “รับรู้และขับเคลื่อน” ได้

Communication

ทำให้อุปกรณ์ “เชื่อมต่อและแลกเปลี่ยนข้อมูล” ได้

ตัวอย่างฟาร์มอัจฉริยะ: เซนเซอร์วัดดินและอากาศ → MCU ตัดสินใจ → สั่งปั๊มน้ำ → ส่งข้อมูลผ่าน MQTT ไปยังแอปของเจ้าของฟาร์ม

เรียนแบบเข้าใจ ไม่ใช่ท่องจำ

เริ่มจากคำถามว่า “ถ้าอยากทำไฟอัตโนมัติ ประตูอัตโนมัติ หรือสถานีวัดอากาศ ต้องใช้บอร์ดแบบไหน เพราะอะไร” แล้วค่อยดูว่าแต่ละบอร์ดเกิดมาแก้ปัญหาอะไร

  • Arduino เกิดมาให้คนทั่วไปสร้างอุปกรณ์อิเล็กทรอนิกส์ได้ง่าย
  • ESP32 เกิดมาเพราะโลกต้องการอุปกรณ์ที่ต่ออินเทอร์เน็ตได้
  • micro:bit เกิดมาเพื่อการศึกษา จึงมีเซนเซอร์และ LED ในตัว
  • Raspberry Pi เกิดมาให้ทุกคนมีคอมพิวเตอร์ราคาถูก
  • TESAIoT Dev Kit เกิดมาให้เห็นระบบจริงที่มีเซนเซอร์ จอ การสื่อสาร ความปลอดภัย และ AI ในชุดเดียว

สรุปสั้น

  • Embedded = สมองเล็กในอุปกรณ์ที่ควบคุมสิ่งต่าง ๆ ได้
  • IoT = อุปกรณ์ที่ต่ออินเทอร์เน็ตและส่งข้อมูลได้
  • Edge AI = AI ที่รันบนอุปกรณ์เอง ไม่ต้องส่งข้อมูลทั้งหมดขึ้นคลาวด์
  • TESAIoT Dev Kit = บอร์ดรวมทุกอย่างไว้ในชุดเดียวสำหรับเรียน AIoT จริง
  • BENTO IDE = เว็บสำหรับเขียนโค้ดและทดลองบอร์ดได้ง่าย
